# Brain Command Center — Live Demo Preview

This is a **preview/demo build** of Brain Command Center, ready to upload straight to GitHub Pages.

## What's different in this build vs. the real app

- **Nothing saves.** Visitors can click around, add tasks, type notes, grow the garden — all of it works, but nothing persists. Reload the page and it resets to a clean starting state. This is intentional, so anyone previewing it doesn't leave data behind and every visitor gets the same fresh experience.
- **A dismissible banner** at the top tells visitors it's a preview and that nothing they add is saved.
- **A "Get Your Copy" button** in the sidebar (desktop) and bottom nav (mobile), currently pointing to a placeholder link: `https://your-link-here.com`. Swap this for your real product/purchase link when you have it (see below).

## How to deploy this to GitHub Pages

1. Unzip this file — you'll see `index.html` and an `assets` folder.
2. Create a new GitHub repository (or use an existing one).
3. Upload `index.html` and the `assets` folder to the **root** of that repo (drag-and-drop works fine on github.com — no command line needed).
4. In the repo, go to **Settings → Pages**.
5. Under "Build and deployment," set **Source** to "Deploy from a branch."
6. Set **Branch** to `main` (or your default branch) and folder to `/ (root)`.
7. Click Save. GitHub will give you a live link within a minute or two — usually:
   `https://yourusername.github.io/your-repo-name/`
